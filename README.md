# Jakub Jatkowski — Portfolio

Oficjalna strona portfolio Jakuba Jatkowskiego — montażysty wideo (Rolki, TikTok, Shorts, wideo reklamowe) oraz projektanta graficznego i DTP.

## Zastosowane technologie
- HTML5 (semantyka i dostępność)
- Vanilla CSS3 (nowoczesny design system, dark mode, responsywność)
- Vanilla JavaScript (typewriter, filtry kategorii, modal lightbox, formularz kontaktowy)
